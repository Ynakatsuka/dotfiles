# 新規執筆

テーマやメモから文章を作る場合に使う。既存原稿の推敲では、原文の構成と声を優先する。

1. 読者、用途、読後に伝える内容を、依頼から分かる範囲で捉える。主張とその根拠を一文ずつ
   言えるか確かめる。一般論しか書けない場合は、ユーザーが渡した素材や利用可能な情報源を
   確認する。必要な固有名詞、数値、体験、根拠を推測で補わない。欠けた情報が文章の核なら、
   何が必要かを具体的に聞く。
2. 長い文章では見出しと各段落の役割を下書き前に並べる。見出しだけで話の流れを追えるか、
   読者が知りたい答えを不必要に待たせていないか確認する。短い連絡文に見出しを足さない。
   見出しは内容に応じて書き、すべてを同じ文型に揃えない。
3. 根拠の多い論点に説明量を割き、軽い論点を無理に膨らませない。因果や経緯は文でつなぎ、
   比較や決定事項など独立した項目は必要に応じて箇条書きにする。専門用語は読み手に必要な
   範囲で説明する。結論を先に示すかは、文書の用途と読み手の期待から決める。
4. 下書き後は見出しと各段落の冒頭を続けて読み、論旨の飛躍、重複、均一すぎる節の長さ、
   同じ書き出しの反復を探す。全文では主語と述語の距離、修飾先、読点の位置、文の息継ぎ、
   抽象的な一般論だけの箇所を確認する。指摘は修正の候補として扱い、意味や意図に必要な
   表現は残す。禁止語の件数や機械的な点数を合格条件にしない。
5. 最後に、主張が根拠の範囲を超えていないか、事実・予定・推測が区別されているか、
   ユーザーの指定した文体と形式に合うかを確かめる。初稿の推敲は、見つかった問題に絞る。
