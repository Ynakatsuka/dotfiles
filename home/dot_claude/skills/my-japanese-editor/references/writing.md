# 新規執筆

テーマやメモから文章を作る場合に使う。既存原稿の推敲では、原文の構成と声を優先する。

1. 読者、用途、読後に伝える内容を、依頼から分かる範囲で捉える。主張とその根拠を一文ずつ
   言えるか確かめる。主張を固有名詞、数値、具体的な出来事なしで説明できてしまうなら、素材が
   足りない。Web検索を使える場合は、仮の主張と根拠を立て、検索で裏づけるか崩してから組み直す。
   使えない場合は、ユーザーが渡した素材を確認する。必要な固有名詞、数値、体験、根拠を推測で
   補わない。欠けた情報が文章の核なら、何が必要かを具体的に聞く。用途が
   `references/genre-profiles.md` のいずれかの節に当たる場合は、その節も読む。
2. 長い文章では見出しと各段落の役割を下書き前に並べる。見出しだけで話の流れを追えるか、
   読者が知りたい答えを不必要に待たせていないか確認する。短い連絡文に見出しを足さない。
   見出しは内容に応じて書き、すべてを同じ文型に揃えない。見出しで本文より確度を上げず、
   結論に条件が付く節は話題を示す見出しにする。
3. 根拠の多い論点に説明量を割き、軽い論点を無理に膨らませない。濃淡は分量の差であり、並列の
   項目に順位を付けない。因果や経緯は文でつなぎ、比較や決定事項など独立した項目は必要に応じて
   箇条書きにする。結論を先に示すかは、文書の用途と読み手の期待から決める。
   - 専門用語は、何をするものかを先に説明してから名前を出す。物の呼び名は読み手がその分野で
     使う呼び名にそろえ、短いたとえや言い換え（公開エンドポイントを「入口」）で済ませない。
     素材の作業用の名前（実験の条件名、ブランチ名）を出さず、文書の中で新しい呼び名を作らない。
   - 断定できることは断定し、推定と未確認を書き分ける。事実には出典を添え、意見は誰の考えかを示す。
   - 打ち消しは、読み手が実際に誤解しそうな場面と、注意として要る場面だけに使う。
   - 太字は文書全体で本当に目立たせたい箇所だけにし、絵文字や記号で飾らない。
4. 下書き後は見出しと各段落の冒頭を続けて読み、論旨の飛躍、重複、均一すぎる節の長さ、
   同じ書き出しの反復を探す。定義文の型、節の組み立て、書き出しが3回続いたら、内容に合わせて
   文の順序や主語を組み替える。疑問形や体言止めを、型を崩すためだけに入れない。全文では主語と
   述語の距離、修飾先、読点の位置、文の息継ぎ、抽象的な一般論だけの箇所を確認する。さらに
   `references/review.md` の「読み手が何のことか取れない言い回し」を段落ごとに確かめる。書いた
   モデル自身は自然だと感じるため、通読だけで済ませない。指摘は修正の候補として扱い、意味や意図に
   必要な表現は残す。禁止語の件数や機械的な点数を合格条件にしない。
5. 結びで本文の要約を繰り返さない。素材から導いた提案は提案と分かるように書き、根拠の範囲を
   超えない。最後に、主張が根拠の範囲を超えていないか、事実・予定・推測が区別されているか、
   ユーザーの指定した文体と形式に合うかを確かめる。初稿の推敲は、見つかった問題に絞る。
