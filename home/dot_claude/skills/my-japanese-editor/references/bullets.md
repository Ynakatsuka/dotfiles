# チーム共有用の箇条書き

そのまま社内チャネルや文書へ貼れる、装飾のない箇条書きに編集する。
入力と依頼の言語を保つ。日本語以外では、見出しや項目名も同じ言語にする。

## 構成

- 今決める必要がある事項がある場合は、最初に「論点」を置く。単なる話題ではなく、
  何を相談または決定するかを書く。
- 論点がない場合は、要点または依頼から始める。
- 必要な項目だけを短い見出し付きの第一階層にする。
- 根拠や補足は、その項目の下へ入れる。
- 箇条書き記号にはハイフンだけを使う。太字、斜体、見出し、引用、インラインコード、
  区切り線などのMarkdown装飾は加えない。
- ユーザーが見出しや項目名を指定した場合は、それに従う。
- 元の文章と依頼に合わせて、項目名と言葉遣いを選ぶ。

依頼に形式指定がない場合は、必要な項目だけを次から選ぶ。

```markdown
- 論点
  - [今相談または決定すること]
- 要点
  - [最も重要な内容]
- 背景
  - [理解に必要な事実]
- 決定
  - [決まったこと]
- 対応
  - [行うこと]
    - 担当: [元の文章にある場合だけ]
    - 期限: [元の文章にある場合だけ]
- 依頼
  - [相手に求めること]
- 未解決事項
  - [今後確認すること]
```

## 編集規則

- 一つの箇条書きには一つの内容を書く。
- 日本語では、簡潔な常体、短い句、体言止めを基本とする。相手や用途から敬体が必要な
  場合は敬体にする。
- 決定、依頼、担当者、期限が分かっている場合は明示する。
- 担当者、期限、決定、状態、証拠がない場合は補わない。
- 「論点」は今決める事項に使い、「未解決事項」は後で確認する事項に使う。
- 空の項目、結論の重複、挨拶、内容のない前置きを削る。
- ユーザーが別途送信を依頼していない限り、投稿や送信は行わない。
