# my-pr Commands

Use this reference after loading my-pr to decide the execution path. Each command is explicit about whether it may edit files, commit, push, or create/update a PR.

Local orchestration artifacts under .tmp/my-pr/ are allowed when generated by my-pr scripts. They must never be staged or committed.

## Command summary

| Command | Purpose | May edit | May commit | May push | PR create/update |
|---|---|---:|---:|---:|---:|
| default | Full PR workflow | yes | yes | yes | yes |
| create | Create/update PR without local correctness review | yes | yes | yes | yes |
| review | Collect and integrate review findings only | no | no | no | no |
| fix | Fix Required findings, verify, and commit | yes | yes | no | no |
| simplify | Run integrated simplify apply only | yes | yes | no | no |
| verify | Verify existing PR checks/reviews only | yes | yes | yes | no |

## Shared gates

`review` uses the Review-only Safety gate. On a protected branch it stays in place and must not invoke worktree transfer/cleanup, reset, checkout, rm, stage / git add -N, commit, push, PR mutation, or ref fetch. It may create only the explicit ignored .tmp/my-pr/ orchestration artifacts.

For default, `create`, `fix`, and `simplify`, the normal protected-branch worktree flow remains mandatory before work that may later be committed.

For default, `create`, `fix`, and `simplify`, complete these gates before simplify, commit, push, or PR creation:

1. Resolve the base branch. Do not guess main.
2. Fetch the base branch only into refs/remotes/origin/$BASE_BRANCH; never advance a local protected branch ref.
3. Run prepare-review-artifacts.sh and preserve its single absolute artifact.env path.
4. Pass that exact path to prepare-pr-context.sh. Do not rely on a previous shell environment or latest-env.sh.
5. If MY_PR_SCOPE_GATE is not ok, stop. Resolve large and untracked according to SKILL.md, then regenerate artifacts.
6. Use the generated repo-local artifacts for review and PR body work. Do not use /tmp review patches.

For `review`, resolve and verify an existing remote-tracking base ref without fetching it, run prepare-review-artifacts.sh, pass its exact artifact.env path to prepare-pr-context.sh, and use only the generated repo-local artifacts. If MY_PR_SCOPE_GATE is `untracked` or `large+untracked`, stop and report without staging, git add -N, or excluding files by changing repository state.

For the default, review, and fix quality stage, use only host-native subagents. Start `reviewer` and `simplifier` for every assigned chunk concurrently where capacity permits. Wait for every result before integration. A launch, execution, artifact-access, status, or result-format failure is `REVIEW_INCOMPLETE`; do not substitute another executor. An oversized-file skip is `COMPLETE_WITH_SKIPS`.

## default

1. Safety gate
2. Base and PR state
3. Prepare repo-local review and PR context artifacts, then pass the scope gate
4. Run native `reviewer` and `simplifier` in read-only mode for every full diff or chunk
5. Wait for all results and integrate findings
6. Fix Required findings
7. Commit fixes
8. Create/update draft PR
9. Verify checks and automated review comments

## create

1. Safety gate
2. Base and PR state
3. Prepare repo-local review and PR context artifacts, then pass the scope gate
4. Delegate simplify apply mode to the native `simplifier_apply` role
5. Main inspects the resulting diff, runs verification, and commits changes if any
6. Create/update draft PR
7. Verify checks and automated review comments

create still runs simplify. It skips only the local correctness review stage.

## review

1. Safety gate
2. Base and PR state
3. Prepare repo-local review and PR context artifacts, then pass the scope gate
4. Run native `reviewer` and `simplifier` in read-only mode for every full diff or chunk
5. Wait for all results
6. Integrate findings
7. Stop

review is read-only. It must not edit files, write notes, run fix verification, transfer or clean up a worktree, reset, checkout, rm, stage / git add -N, commit, push, fetch refs, or create/update a PR. It may create only the explicit ignored .tmp/my-pr/ orchestration artifacts.

## fix

1. Safety gate
2. Base and PR state
3. Prepare repo-local review and PR context artifacts, then pass the scope gate
4. Run native `reviewer` and `simplifier` in read-only mode for every full diff or chunk
5. Wait for all results and integrate findings
6. Fix Required findings only
7. Run the verification plan for the fixes
8. Commit fixes if any
9. Stop

fix must not apply Recommended findings, push, or create/update a PR. If a Required finding needs a public API, schema, CLI, config, persistence, or documented error semantic change, stop and report instead of editing.

## simplify

1. Safety gate
2. Base and PR state
3. Prepare repo-local review and PR context artifacts, then pass the scope gate
4. Delegate simplify apply mode to the native `simplifier_apply` role
5. Main inspects the resulting diff, runs verification, and commits changes if any
6. Stop

simplify does not run correctness review, fix non-simplification findings, push, or create/update a PR.

## verify

1. Resolve PR number and head branch
2. Poll checks
3. If checks fail, inspect logs, fix root cause, test, commit, push, and poll again
4. Inspect automated review threads, review bodies, and top-level comments
5. Fix actionable HIGH/critical and valuable MEDIUM/warning findings
6. Commit and push fixes if any

verify must not create/update a PR or mark a PR ready. It may edit, commit, and push fixes for the existing PR branch.
